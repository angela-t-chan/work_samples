Two interfaces,
one shared feedback model

The bystander and the expert dispatcher see the same waveform signal — the bystander's compressions overlaid on the target rhythm. The interfaces differ in what they add around it: the bystander gets a single match rate and one corrective message; the expert gets live metrics and incident context to support real-time guidance.

Design rationale

I designed the interface around a shared feedback model: both users see the same core compression signal, but each view is scoped to the decisions that person needs to make in the moment.

Shared waveform

Both views use the same target-vs.-actual waveform. The "MATCH HERE" marker gives the bystander a simple timing target and gives the expert a shared reference point for real-time coaching.

Asymmetric information

The bystander sees one number and one directive. The expert sees match rate, compression rate, depth, and incident context. The asymmetry is intentional — the bystander should act, while the expert interprets.

Open question

The next evaluation phase would test whether real-time waveform visibility improves compression quality or creates distraction under simulated stress, especially for first-time bystanders.
